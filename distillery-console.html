Oracle NetSuite ERP Layer

NetSuite remains the source of truth for accounting, inventory, sales orders and invoices. E.L.Y.A.S. acts as the asset intelligence, monitoring and market-access layer.

Integration Pattern: Frontend → E.L.Y.A.S API → NetSuite Connector → Oracle NetSuite.
Security: Credentials stay in backend environment variables, never in browser code.
Sync Mode: Queue-based sync for inventory, orders, invoices and commission entries.
Future: SuiteTalk REST Web Services + OAuth 2.0 backend connector.
